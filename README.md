# CS229 讲义逐节精读 · 网页版

在线阅读：**https://mazh114.github.io/cs229-study-guide/**

斯坦福 CS229（机器学习）全 17 章 + 第 0 章预备知识的逐节精读讲义，由 Typst 源文件编译为单页静态网页。数学推导与核心证明保留原讲义英文（偏僻词附中文注释），例子叙述、代码、习题为中英双语。

## 功能

| 功能 | 说明 |
|---|---|
| 侧边栏目录 | 全书 19 章 / 86 小节，点击直达；章节可展开收起；左上角 ☰ 收起整个侧边栏；阅读时自动高亮当前小节 |
| 多用户进度 | 打开网页可创建/切换用户名，打卡进度按用户独立保存在浏览器 localStorage |
| 打卡系统 | 每章开头一张大打卡卡（含"小节完成 x/y"进度条，全部完成变绿）；每个小节和习题旁有小打卡胶囊，勾选后记录打卡日期 |
| 进度导出/导入 | 顶栏可导出当前用户进度为 JSON 文件，换设备时导入即可迁移 |
| PDF 下载 | 首页提供完整 127 页 PDF 版下载 |

## 目录结构

```
├── index.html               # 网页主文件（含全部内容与样式/脚本）
├── CS229讲义逐节精读.pdf    # PDF 版讲义
└── figs/                    # 讲义插图
```

## 使用说明

- 打开网页后先在弹窗中创建用户名（如"小明"），打卡数据与该用户绑定；切换用户即查看各自进度。
- 打卡数据保存在当前浏览器中，清除浏览器数据会丢失进度，请定期使用"导出进度"备份。
- 需在本地使用时，直接用浏览器打开 `index.html` 即可，无需服务器。
